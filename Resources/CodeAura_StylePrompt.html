04 — Tags & Card Variants

Feature labels and card accents

M1 · MANDATORY

Teal Card

Use for primary features, active states, confirmed data, successful outcomes. The default accent — most used.

B1 · BONUS

Amber Card

Use for warnings, bonus features, alternate sections, or priority callouts that need visual separation.

◈ AI FEATURE

Blue Card

Use exclusively for AI-powered features, informational panels, chatbot UI, and RAG-related components.

🔴 CRITICAL

Red Card

Use for errors, blocked states, critical warnings, and risk flags. Never use decoratively.

07 — Agent Cheat Sheet

One-line reminders for your coding agent

Design constraints to apply to the component above: Fonts: Syne for display text, Space Mono for all labels, code, and data. Background: #0a0c10 page bg, #12161e cards, #161b24 elevated surfaces.
